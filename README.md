# 🌿 Proyecto Final Integrador - EcoTech Solutions

Trabajo Práctico Final de Programación (Python & Django). El proyecto simula una empresa de tecnología sustentable y se compone de tres módulos independientes.

## 📂 Estructura del Repositorio

- **Ejercicio_1/**: Sanitización y análisis estadístico de datos de sensores de consumo energético.
- **Ejercicio_2/**: Modelo de inventario orientado a objetos (OOP), herencia (`DispositivoEcológico` y `PanelSolar`), excepción personalizada `StockInvalidoError` y persistencia de datos en JSON (`GestorInventario`).
- **Ejercicio_3/**: Auditoría de algoritmo de emisiones de carbono mediante pruebas unitarias (`unittest`) e integración web completa utilizando el patrón MVT de **Django** (servicios, vistas, urls, tests y plantilla HTML administrativa `panel.html`).

## 🛠️ Tecnologías Utilizadas
- Python 
- Django 
- Unittest 
- Interfaz web
